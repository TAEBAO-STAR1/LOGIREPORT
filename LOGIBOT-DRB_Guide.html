🎯 LOGIBOT이 해결하는 핵심 문제

"물류팀에게 문의 할 사항을 직접 전화해야 하나요?" — 더 이상 그럴 필요 없습니다.
컨베어벨트 롤 직경 계산, 수출 PLT 포장 수량, 운임 비교까지 채팅창 하나로 즉시 해결하세요.

⚡ Why LOGIBOT?

우리가 겪어온 비효율,
이제는 끝낼 때입니다

영업팀이 매일 반복하는 물류 문의 사이클을 데이터로 살펴봤습니다.
세 가지 핵심 문제가 업무 효율을 갉아먹고 있었습니다.

📞
전화 업무 과부하
배차 가능 여부, 규격 확인, 납기 조회 등 단순 반복 질문으로 하루에도 수십 건의 전화가 물류팀과 영업팀 사이를 오갑니다. 상담 중 걸려온 전화, 이동 중 받기 어려운 전화. 양쪽 모두 집중 업무가 불가능합니다.
📊
수동 데이터 산출
수출 포장량 계산, 컨베어벨트 롤 직경 산출, 배차 차량 선정 — 이 모든 과정이 엑셀 파일을 열고 수식을 직접 입력하는 방식입니다. 수식 오류, 버전 불일치, 최신 데이터 반영 지연이 항상 리스크였습니다.
🗃️
정보 접근성 격차
물류 규정, 담당자 연락처, 차량 제원 데이터가 여러 파일과 공유폴더에 흩어져 있습니다. 신입 직원은 물론 베테랑 영업사원도 "어디에 있었더라..." 하고 검색하는 데 귀한 시간을 씁니다.
📈 문제가 발생하는 전형적인 시나리오
내부 문의
물류팀 또는 동료에게 전화·메신저로 문의 → 상대방 업무 중단, 5~30분 대기
엑셀 계산
담당자가 엑셀 파일 찾아서 열고, 수치 입력, 계산 → 오류 가능성, 파일 버전 문제
재연락
결과값 다시 영업사원에게 전달 → 영업사원이 고객에게 재연락 → 총 소요 시간: 30분~1시간
💡 왜 지금인가?
🔬 기술이 준비되었습니다

사내 온프레미스 모델과 Qdrant Vector DB를 통해 사내 데이터를 외부에 유출하지 않으면서 고품질 AI 답변이 가능해졌습니다. 이전까지는 불가능했던 조합입니다.

📂 데이터가 준비되었습니다

물류팀이 그간 축적해온 차량 데이터, 포장량 기준, 노선 데이터, 담당자 정보가 디지털화되어 AI가 즉시 참조할 수 있는 형태로 정리되었습니다.

🧠 Architecture

LOGIBOT은
어떻게 동작하나요?

복잡한 AI 기술을 최대한 쉽게 설명합니다.
크게 3단계로 이해하면 됩니다.

자연어 질문 입력

채팅창에 자연어로 질문을 입력합니다. "6004010 자재에 대한 직경을 알려줘" 같이 평소 말하듯이 입력하면 됩니다. 자재코드, 지역명, 업무 키워드 모두 인식합니다.

💡 자재코드 7자리만 입력해도 해당 자재의 모든 규격 정보를 자동으로 찾습니다

AI 지식 검색 (RAG)

질문의 의미를 분석해서 사내 데이터베이스에서 가장 관련 있는 문서를 찾습니다. 단순 키워드 검색이 아니라 의미 기반 벡터 검색으로 더 정확하게 찾아냅니다.

💡 컨베어벨트 직경 계산인지, 배차 시뮬레이션인지, 포장량 계산인지 자동으로 도메인을 감지합니다

AI 답변 생성

찾아낸 데이터를 바탕으로 사내LLM 모델이 명확하고 구조화된 답변을 생성합니다. 계산이 필요한 경우 수식과 과정을 단계별로 보여줍니다.

💡 답변에 '참고문서' 버튼이 있어 AI가 어떤 데이터를 근거로 답했는지 직접 확인할 수 있습니다

학습 & 개선

👍 좋아요를 누르면 해당 답변이 학습 데이터로 저장되어 비슷한 질문에 더 나은 답변을 제공합니다. 👎 싫어요 + 사유를 입력하면 담당자에게 이메일로 즉시 알림이 갑니다.

✨ Core Features

로지봇의
6가지 핵심 기능

단순 챗봇이 아닙니다.
사내 물류 전문 데이터를 기반으로 즉각 계산하고, 추천하고, 안내합니다.

🚚

지능형 배차 시뮬레이터

자재코드와 수량만 입력하면 파렛트 규격을 자동으로 계산하고 최적 차량 톤수를 즉시 추천합니다. 사이드바의 시뮬레이터에서는 실시간 적재율 게이지까지 확인 가능합니다.

자재코드 입력 PLT 자동계산 차량 추천 적재율 표시
📦

수출 포장량 계산기

목표 중량과 포장재 종류, 자재그룹을 선택하면 필요한 박스 수량과 PLT 수를 즉시 계산합니다. 복수 자재그룹도 한 번에 비교·계산할 수 있습니다.

B01·B02·N18·N19 컨테이너 분석 20ft / 40ft
📐

컨베어벨트 직경 계산

자재코드를 입력하면 상고무·하고무·심체 수를 자동으로 찾아 포두께를 계산하고, 컨베어벨트 길이(M)를 입력하면 롤 직경까지 단계별로 산출합니다.

수식 자동 적용 단계별 계산 표시
🗺️

국내 운임 최적 비교

도착 지역과 총 중량을 입력하면 단거리/장거리 판별 후 화물·택배 vs 직송 중 어느 쪽이 유리한지 즉시 알려줍니다.

지역 자동 판별 최적 운임 추천 근거 판단 표시
🔍

RAG 사내 지식 검색

물류 운영 규칙, 담당자 연락처, 주문 마감 시간, 샘플 발송 방법 등 텍스트 정보를 자연어 질문으로 바로 검색합니다. 참고 문서 원문도 키워드 하이라이트와 함께 확인 가능합니다.

담당자 조회 규정 안내 원문 팝업
📁

파일 업로드 분석

엑셀 발주서를 올리면 중량 합산 후 배차 시뮬레이션을 자동 실행합니다. PDF 문서를 업로드하면 텍스트를 추출해 물류 관련 데이터를 분석합니다.

.xlsx / .csv .pdf 텍스트 추출 자동 배차 분석
💡 팁: 대화 히스토리 활용하기

최대 10턴의 대화 맥락을 유지합니다.

📖 User Guide

처음 시작하는 법

LOGIBOT 접속부터 첫 질문까지, 5분이면 충분합니다.

🚀 기본 사용 흐름

접속하기

사내 네트워크(Wi-Fi 또는 VPN 연결)에서 지정된 URL로 접속합니다. 별도 로그인 없이 즉시 사용 가능합니다.

🔗 접속 URL은 사이드바 버튼 혹은 물류팀에서 안내드립니다

팀 선택하기

화면 좌측 상단의 🚚 국내영업팀 / 🚢 해외영업팀 / 🚜 트랙영업팀 버튼 중 내 팀을 선택합니다.

선택하면 팀 맞춤 추천 질문과 전용 시뮬레이터가 활성화됩니다.

추천 질문으로 시작하기

화면에 팀별 추천 질문 6개가 버튼으로 표시됩니다. 클릭 한 번으로 바로 질문할 수 있습니다.

처음에는 추천 질문부터 눌러보며 어떤 답변이 나오는지 확인해보세요.

직접 질문하기

하단 채팅창에 질문을 직접 입력합니다. 평소 동료에게 물어보듯 자연스럽게 입력해도 됩니다. 자재코드, 지역명, 무게 단위 등을 포함하면 더 정확한 답변을 받을 수 있습니다.

✅ 좋은 예: "6004010 자재 100PC 배차할 때 몇 PLT 나와?"
✅ 좋은 예: "부산 지역 500kg 발송 직송이 나아 화물이 나아?"

사이드바 시뮬레이터 활용하기

좌측 사이드바 하단에는 팀별 전용 시뮬레이터가 있습니다. 숫자를 직접 입력하며 실시간으로 계산 결과를 확인할 수 있습니다.

'이 결과로 상세 문의하기' 버튼으로 챗봇과 연동도 됩니다.
💬 질문 잘 하는 법
✅ 이렇게 하면 잘 됩니다
  • 자재코드 7자리를 포함하면 정확도가 훨씬 높아집니다
  • 무게, 수량, 지역 등 숫자 정보를 함께 입력하세요
  • "표로 정리해줘", "단계별로 설명해줘" 같이 형식을 요청해도 됩니다
  • 이전 대화를 이어서 "그럼 그 자재 우든박스 규격도 알려줘"처럼 연속 질문도 가능합니다
  • 정보가 없는 경우 "해당 정보를 찾을 수 없습니다"라고 솔직하게 알려줍니다
⚠️ 이런 점을 주의하세요
  • LOGIBOT은 사내 데이터 기반이라 외부 시세·뉴스는 정확도가 낮을 수 있습니다
  • 계산 결과는 참고용이며, 실제 발주 전 담당자 최종 확인을 권장합니다
  • 개인정보나 기밀 정보는 입력하지 마세요
  • 답변이 이상하면 👎 버튼으로 피드백을 남겨주세요. 빠르게 개선합니다
  • 한 번에 너무 많은 내용을 물어보기보다 질문을 나눠서 입력하면 정확도가 높아집니다

❓ FAQ

자주 묻는 질문

LOGIBOT 사용 전 가장 많이 나오는 질문들을 모았습니다.

LOGIBOT은 항상 정확한 답변을 주나요? +
사내 데이터에 있는 정보는 높은 정확도로 답변합니다. 단, 데이터에 없는 내용은 "해당 정보를 찾을 수 없습니다"라고 솔직하게 안내합니다. 계산 결과는 검증을 거쳐 신뢰할 수 있지만, 실제 발주나 중요한 결정 전에는 담당자에게 최종 확인하는 것을 권장합니다. 오류를 발견하면 👎 피드백으로 알려주세요.
내 질문 내용이 외부에 유출되지 않나요? +
LOGIBOT은 사내 서버에서만 운영되는 온프레미스(On-Premise) 시스템입니다. ChatGPT나 외부 클라우드 AI 서비스를 사용하지 않으며, 모든 대화 내용은 사내 서버에만 저장됩니다. 외부 인터넷으로 데이터가 나가지 않습니다.
팀을 바꾸면 이전 대화 내용이 사라지나요? +
각 팀의 대화 세션은 독립적으로 유지됩니다. 국내영업팀에서 해외영업팀으로 전환해도, 국내영업팀에서 나눈 대화는 다시 국내영업팀으로 돌아오면 그대로 유지됩니다. 단, 브라우저를 완전히 새로고침하면 세션이 초기화됩니다.
계산 결과를 파일로 저장할 수 있나요? +
각 답변 아래의 📋 버튼을 클릭하면 답변 내용을 .txt 파일로 다운로드할 수 있습니다. 이후 엑셀이나 문서에 복사해 활용하세요.
LOGIBOT에 없는 정보를 요청하면 어떻게 되나요? +
사내 데이터에서 답을 찾지 못할 경우, 웹 검색을 통해 일반적인 정보를 제공하려 시도합니다. 이 경우 답변 마지막에 "🌐 웹 검색 기반"이라고 표시됩니다. 웹 기반 답변은 사내 데이터만큼 신뢰도가 높지 않으므로 주의하세요.
스마트폰에서도 사용 가능한가요? +
네, 모바일 브라우저(크롬, 사파리)에서 완벽하게 동작합니다. 사내 Wi-Fi 또는 VPN이 연결된 상태에서 동일한 URL로 접속하면 됩니다. 다만 화면이 작은 경우 사이드바 시뮬레이터보다는 채팅으로 질문하는 것이 편리합니다.
데이터가 틀려 있거나 업데이트가 필요하면 어떻게 하나요? +
👎 부정 피드백 버튼을 눌러 "답변 내용 오류"를 선택하고 추가 의견란에 올바른 정보를 입력해주세요. 담당자에게 자동으로 이메일 알림이 발송되어 데이터를 확인하고 업데이트합니다. 정기적으로 마스터 데이터를 갱신하는 프로세스도 운영 중입니다.
